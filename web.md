-----Pentest-----

PTES: metodologia para condução de um pentest
     -desde a proposta definida até o relatório entregue ao cliente

WSTG: metodologia para pentest desenvolvida pela OWASP para aplicações web

Pentest Report (Relatório): documento desenvolvido a partir de um pentest realizado para o cliente, dentro do report é mencionado todas as vulnerabilidades encontradas e seus respectivos CVE's e quais correções devem ser implementadas.

DNS: registro que transforma o domínio (www.google.com) em um endereço ( 172.56.456.33 )
- serviço DNS local : roteador
- root server: indica qual servidor é o responsável pelo domínio
- serviço DNS autoritativo: indica qual o ip do domínio requisitado
